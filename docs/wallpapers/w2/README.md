# W2 — Dreamy Nights

Four Nompong designs, each independently composed for phone, tablet portrait, tablet landscape and desktop. Created with the built-in image generation tool using the original character reference. Downloads preserve actual generated dimensions; quality-95 full-chroma JPEG. Catalog-only previews use WebP. No cropping, stretching or upscaling.

Designs: Moon Cloud, Lantern Camp, Bedtime Book, Star Window.

The exact prompt set is recorded in prompts.json.

List-view thumbnails: each `*-desktop-thumb.jpg` is a 480×270 JPEG (quality 80) made from the desktop file, used for the wallpaper list rows on phones. Add one for every new design (the list falls back to the full desktop image if it is missing).
