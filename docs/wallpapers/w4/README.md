# W4 — Nompong’s Cozy Café

Four designs: Morning Cup, Window Seat, Bakery Break, Sleepy Café Corner. Each has four separately composed layouts: phone, tablet portrait, tablet landscape, desktop. Total: sixteen downloadable wallpapers.

Generated with the built-in image-generation tool and the original Nompong character reference. JPG downloads retain native dimensions with quality-95 full-chroma export, without upscaling, cropping or stretching. WebP thumbnails and small landscape JPGs are catalog previews. The app uses a consistent portrait preview frame. Exact production prompts are in prompts.json.
