# W5 — Tummy Mischief

Four designs: Tummy Peek, Picking Fluff, Fluff Treasure, Sleepy Tummy.
Each has phone, tablet portrait, tablet landscape and desktop artwork: sixteen downloads.

Built-in image generation uses the original Nompong model sheet and the approved
Tummy Peek artwork as direct references for every layout. Images retain their native
pixel dimensions. JPG exports use quality 95, full chroma, without upscaling, cropping
or stretching. WebP and small landscape JPG files are browsing previews.
