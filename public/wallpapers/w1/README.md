# W1 — Cozy Days with Nompong

Four existing source designs from the Wallpaper Collection Plan chat: Corner Peek, Tail Cuddle, Tummy Time and Sage Hill. Each has separately composed phone, tablet portrait, tablet landscape and desktop artwork (16 downloads).

Downloads retain each source image's exact pixel dimensions, without cropping, redrawing or upscaling, encoded as quality-95 JPEG with full chroma. Small WebP phone previews are for the catalog only. Original PNG sources remain in the user's saved collection. No file is described as 4K or FHD unless it actually has those dimensions. Source dimensions, actual file sizes and relative paths are recorded in `src/features/wallpapers/collection.json`.
